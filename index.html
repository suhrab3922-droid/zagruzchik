Загрузчик

Загрузчик is a personal Windows desktop application for managing the owner's own YouTube channels. It uploads videos, sets titles and thumbnails, and shows channel statistics. It is not offered to the public.

Загрузчик — личная программа для Windows, которая помогает владельцу управлять его собственными каналами YouTube: загружать ролики, задавать названия и обложки, смотреть статистику. Программа не распространяется среди других людей.
