Privacy policy

Загрузчик is a personal desktop application used only by its owner to manage the owner's own YouTube channels.

Data the application accesses

After the owner signs in with Google, the application uses the YouTube API Services to:

  • upload videos and update their titles, descriptions, tags, thumbnails and privacy settings;
  • read channel names, pictures, banners and subscriber counts;
  • read channel and video statistics, including views, watch time, countries and thumbnail click-through rate.

Where data is stored

All data stays on the owner's own computer. Access tokens are stored in Windows Credential Manager. Settings, channel information and statistics are stored in a local database. The application has no server and does not send this data anywhere except to Google and YouTube, which is required for it to work.

Sharing

The application does not sell, share or transfer user data to anyone, and does not use it for advertising.

Google API Services User Data Policy

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

The application uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. The Google Privacy Policy also applies.

Removing access and data

Access can be revoked at any time in Google Account permissions. Disconnecting a channel in the application removes its access token. Deleting the application's data folder removes all locally stored data.

Политика конфиденциальности (кратко)

Загрузчик — личная программа её владельца. Данные каналов и статистика хранятся только на его компьютере и передаются только в Google и YouTube, это нужно для работы программы. Данные не продаются и никому не передаются. Доступ можно отозвать в настройках аккаунта Google.
